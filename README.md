# Promociones App - Desafío Angular

Este proyecto es una aplicación en Angular para la gestión de promociones de productos, cumpliendo los requisitos de un desafío práctico.  

## 🚀 Cómo correr el proyecto

### Instalar dependencias

npm install

###Ejecutar la aplicación

ng serve

### Luego abre tu navegador en:

http://localhost:4200/
